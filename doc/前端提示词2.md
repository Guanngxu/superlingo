**角色设定**
你是一位经验丰富的前端架构师和高级开发工程师。请帮我使用 Vue3 开发一个协助在美华人购买商品的单页 H5 扫码应用。请严格遵循“Simplicity First”（简单优先）的原则，提供能解决问题的最简代码，同时具备现代化 App 的精美视觉体验。

**技术栈与规范要求**

1. **核心框架**：Vue3 (使用 `<script setup>` 组合式 API) + TypeScript + Vite。
2. **UI 库**：Vant 4（移动端优先）。
3. **第三方依赖**：仅限引入轻量级的扫码库 `html5-qrcode`。禁止引入条形码生成库（直接展示文本即可），禁止引入其他多余的大型插件。
4. **样式**：严格使用 Scoped Less 编写，底层背景色使用原生 iOS 风格的浅灰色 (`#f2f2f6`)。禁止使用任何内联样式（Inline Styles）。
5. **响应式**：以移动端（H5）体验为主，最大宽度限制为 600px 居中展示，适配 PC 和平板。
6. **动画与交互**：页面切换、弹窗、Tab 切换等交互需结合 Vant 4 内置动画平滑过渡。
7. **代码质量**：
* 遵循 TSLint/ESLint 规范，代码需添加必要的业务注释。
* 适度模块化（抽离 API、类型和核心组件），不要过度拆分。
* 绝对禁止使用过时的 API 写法（如 Vue2 Options API）。


**业务流与功能需求**

1. **扫码模块 (`Scanner.vue`)**：
* 初始页面为扫码页，支持调用摄像头实时扫码（需设置横向较大的扫码框，如宽 90% 高 180px），或扫描本地相册图片。
* **细节约束**：从相册识别前，务必先停止摄像头底层流；底层库实例化时保持最简配置，无需配置特定的 formats 避免引发解析 bug。
* “从相册选择识别”按钮需采用现代感设计：深石板灰 (`color="#2d3436"`) 的圆角 (`round`) Block 按钮。


2. **数据请求与状态管理**：
* 识别出 `barcode` 后，向后端发起 GET 请求：`[https://superlingo.onrender.com/api/v1/scan/](https://superlingo.onrender.com/api/v1/scan/){barcode}`。
* 需处理 Loading 加载态，并做防抖处理避免重复请求。


3. **404 与异常处理**：
* 接口返回 `code: 404` 或失败时，展示“商品未录入”的空白详情页（`<van-empty>`），下方提供深石板灰色的“返回扫码”按钮。


4. **结果展示模块（现代化卡片流布局）**：
   数据成功返回后，页面分为上、下两个包裹在现代化白色卡片（带圆角和微阴影）内的部分：
* **上半部分（核心商品信息卡片）**：
* **顶部弱化说明**：卡片最上方有一条虚线底边的浅色小字说明：“说明：加工程度按 1 至 4 级递增，1为未加工，2为加工过的烹饪原料，3为加工食品，4为超加工食品。”
* **主内容区域（严格水平整体居中）**：采用 Flex 左右布局，但内部图文作为一个整体水平居中。
* **左侧图**：固定宽度（约 130px），展示商品图片。
* **右侧文**：紧凑排布。首行为品牌名称（大字/加粗，不带“品牌”二字）；接着是中英文名称；条形码字符串（等宽字体）；重量参数（纯文本展示，非 Tag）；最后是“加工程度” Tag。
* **动态色彩**：加工程度(novaGroup)的 Tag 需根据 1-4 级动态着色（1-绿色，2-黄色，3-橙色，4-红色）。




* **下半部分（Tab 详情卡片）**：
  使用 Vant 的 `<van-tabs>`，包含以下四个标签页：
* **成分列表 (ingredients)**：需按逗号/分号拆分成行。利用正则（严格匹配带 `%` 号的数字，如 `\d+(?:\.\d+)?%`，避免误伤如 `E170i` 的成分名）提取出百分比。每行成分需使用绝对定位生成一个浅绿色的**百分比背景进度条**，右侧高亮显示具体百分比文本。
* **原料 (origins)**：纯文本展示。
* **所属类别 (categories)**：按逗号拆分为数组，使用预设的 5 种柔和色彩（如浅蓝、浅绿、浅橙、浅红、浅紫）交替渲染为多色 Tag 矩阵。
* **可出售国家 (countries)**：纯文本展示。




5. **数据容错（空值处理）**：
* 接口字段中除图片、中英文名称、条形码外，其余字段均可能为空。
* 检测到空字段时，自动隐藏对应 UI 元素。某个 Tab 对应内容为空时，不渲染该 Tab 标签。


6. **便捷重扫**：
* 详情页底部必须有一个静态定位（不使用 fixed，防止移动端键盘或导航栏遮挡）的“继续扫码”按钮。样式需与扫码页按钮严格统一（深石板灰色、圆角、Block）。



**数据结构与接口契约**

* 成功返回：`{ "code": 200, "message": "success", "data": { ... } }`
* 失败返回：`{ "code": 404, "message": "未找到商品信息" }`
  请根据下方 Java 实体类推导并定义 TS Interface：

```java
public class Product {
    private String barcode; // 条形码
    private String nameZh; // 中文名称
    private String nameEn; // 英文名称
    private String imageUrl; // 图片
    private String source; // 来源
    private String quantity; // 重量信息（包含单位）
    private String brands; // 品牌
    private String categories; // 类别
    private String countries; // 可出售国家
    private String origins; // 原料来源
    private String ingredients; // 成分及占比
    private Integer novaGroup; // 加工程度：1-4
}

```

**任务执行要求**
请按照以下文件结构依次输出代码，确保代码完整可直接运行：

5. `App.vue`: 主应用入口，管理全局状态与视图切换（包含 fade 过渡动画）。
