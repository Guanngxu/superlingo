# 技术栈

1. 框架：Vue3
2. 开发语言：TypeScript
3. UI 组件：Vant 4

# 交互

1. 需要适配移动端，并且 H5 最为重要
2. PC 端和平板也需要实现自适应
3. 点击展开、弹出模态框等均有过渡动画

# 禁止与约束

1. 禁止引入多余的第三方大型插件
2. 禁止使用过时的 API 写法
3. 禁止使用内联样式
4. 代码需要模块化，但不必为了划分模块而写出过多模块
5. 代码需要添加必要的注释，且符合 TSLint 规范
6. 样式使用 Scoped Less

# 业务场景

一个协助在美华人购买商品的小软件（可以做成单页应用），用户扫描商品条形码后可以展示出来这个商品的信息（后端提供，且已经翻译好）

# 功能

1. 用户打开网址后可以选择使用摄像头扫码，也可以扫描本地相册图片；
2. 当识别到 barcode 后自动向后端发送请求获取该商品的数据（接口为：https://superlingo.onrender.com/api/v1/scan/{barcode}）
3. 后端返回的所有信息都需要展示，页面分成两部分，上半部分为主要信息（商品图片、中英文名称、品牌、加工程度、重量、条形码），下半部分用不同 tab 页放置信息；
4. tab 页信息包括成分信息、原料来源、可出售国家、分类信息；
5. 商品图片、中英文名称、条形码一定会有，但是其它字段可能没有甚至可能为 null，所以遇到没有信息的时候可以直接不展示对应的tag或tab；
6. 条形码不是简单的一串数字，能够直观的根据barcode渲染出来逼真的条形码；
7. 用户扫完一个条形码后可能需要扫别的条形码，所以需要有清晰方便的返回扫码页面按钮；
8. 加工程度后端返回的是一个数字，所以需要进行转换：1、未加工或低度加工的食品，2、加工过的烹饪原料，3、加工食品，4、超加工食品；
9. 404错误处理：展示一个“商品未录入”的空白详情页并提供返回按钮

```java
public class Product {

    private String nameZh; // 中文名称

    private String imageUrl; // 图片
    private String source; // 来源：AUTO 表示自动填写
    private String quantity; // 重量信息（包含单位）
    private String brands; // 品牌
    private String categories; // 类别
    private String countries; // 可出售国家
    private String origins; // 原料来源
    private String ingredients; // 成分及占比
```
